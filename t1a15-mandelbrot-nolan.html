Understanding the Mandelbrot Set

The Mandelbrot Set is one of the most famous examples of mathematical fractals, created by repeating a simple complex equation continuously.

Zn+1 = Zn2 + C

How it works:

  • C represents each point (pixel position) on the complex coordinate grid.
  • Z starts at zero (0 + 0i) for every pixel.
  • We calculate iterations repeatedly: square Z and add C.
  • If the magnitude |Z| > 2, the point escapes to infinity and is outside the set.
  • Points that remain bounded forever belong inside the black set boundary.

Smooth Continuous Coloring:

To avoid ugly banding artifacts when zooming, continuous fractional iterations are computed using smooth logarithmic coloring:

Color = i + 1 - log(log(|Z|)) / log(2)

Navigation Controls:

  • Mouse Move: Positions the zoom frame preview box.
  • Mouse Wheel: Expands/shrinks the zoom frame scale factor.
  • Left Click: Zooms straight into the center of the selection box.
  • Right Click: Zooms back out by 2x.
  • Reset Button: Returns to full view of the main fractal set.
