JSON (JavaScript Object Notation) is a lightweight data transfer format that is easy for humans to read and write, and easy for machines to parse and generate.
It is often used for transmitting data in web applications between a server and a client.
Example working code 
{
    "userID" : "1",
    "name" : "Fred Smith",
    "age" : "16",
    "school" : "St. Jimothy Secondary",
    "location" : {
        "address" : "123 John Road",
        "city" : "Vancouver",
        "postalCode" : "V1A 2B3"
    },
    "contacts" : {
        "mobile" : "1-800-FRED",
        "emergency" : {
            "name" : "Alice Smith",
            "relationship" : "Sister",
            "phone" : "1-800-PHON"
        }
    }
}
